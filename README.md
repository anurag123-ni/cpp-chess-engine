# C++ Chess Engine

A learning project to build a command-line chess engine in modern C++.

## Person B — Day 1

Today this project gets its first program, Git repository, and build setup.

## Build in VS Code

Press `Ctrl+Shift+B` and choose **Build chess engine**. This creates
`chess_engine.exe` in the project folder.

Or run these commands in the VS Code terminal:

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic src/main.cpp -o chess_engine.exe
.\\chess_engine.exe
```
